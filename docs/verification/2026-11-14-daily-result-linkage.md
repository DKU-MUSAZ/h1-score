# 하루 한 경기 · 기록·배지·마일리지 연동

## 적용 기준

- 참가 확정 시 한국시간 날짜와 경기 ID를 기기에 동기 저장한다. 내비 요청 실패처럼 참가가 확정되지 않은 경우에는 소진하지 않는다.
- 예약 확정 후 취소, 실격, 필수 정보 확인 불가도 그날 참여에 포함한다. 앱 재실행이나 목적지 변경으로 다시 참가할 수 없다.
- 자정을 넘어 도착해도 원래 참가일에 배지·일일 보상·달력을 반영한다. 실제 도착 시각은 별도로 유지한다.
- 실제 모드와 시연 모드는 참가 내역, 배지 진행률, 지갑, 표시 기록을 분리한다. 읽기 전용 예시 기록은 참여 제한과 지갑을 변경하지 않는다. 같은 날 실제로 실행한 시연 결과가 있으면 해당 날짜의 예시 카드는 숨긴다.

| 결과 | 내 기록 | 배지·경기 보상 |
|---|---|---|
| 당일 참가권을 가진 정상 완료, 회차 내 도착, 참가 거리·유효 데이터 충족 | 점수·인정 여부·배지 내역 저장 | 기존 배지 조건 적용, 시연 경기 순위 보상 적용 |
| 운전석/탑승 조수석 벨트 실격 | 실격 사유, 점수 없음 | 제외 |
| 필수 차량 정보 확인 불가 | 확인 불가 사유, 점수 없음 | 제외 |
| 대회 종료 시각 이후 도착 | 시간 초과 실격, 점수 없음 | 제외 |
| 거리/데이터 부족·그 밖의 회차 외 결과 | 개인 분석 기록, 불인정 사유 | 제외 |
| 동일 결과 재전달 | 최초 저장 결과 유지 | 중복 지급하지 않음 |

점수 계산식은 변경하지 않았다. 급가속·급감속·제한속도 채점은 기존 그대로이며 차선변경은 관찰 전용이다. 실제 랭킹 서버 연동은 이번 범위에서 제외했다. 실제 모드도 인정된 개인 결과로 일반 배지와 배지 마일리지는 집계할 수 있지만 실제 경기 순위 보상은 서버 연동 전까지 지급하지 않는다. 환영 배지 보상은 없다.

## 기록과 보상 연결

`CompletedDrive`에 참가일, 결과 인정 사유, 획득 배지 ID·제목·조건·마일리지를 저장한다. 내 기록 상세의 마일리지 내역에서 경기 보상과 배지 보상 및 개별 획득 배지를 확인한다. 배지 진행률은 같은 날짜의 첫 인정 점수를 유지한다. 기존 기록의 점수와 지급 내역을 소급 재계산하지 않는다.

## 이어갈 습관·개선할 점 문장 생성

생성형 AI 호출 없이 **저장된 채점 보고서 → 조건 분기 → 문장 템플릿 → 값 치환** 순서로 생성한다. 파일은 `HabitText.kt`, `HistoryFeedback.kt`다.

| 근거 | 템플릿 예 |
|---|---|
| 제한속도 준수 거리 | 제한속도를 지킨 구간이 `{distance}` 있었어요. |
| 실제 속도 가점 | 제한속도 준수로 `{points}`점을 쌓았어요. |
| 과속 거리 | 제한속도를 초과한 거리가 `{distance}`예요. 제한속도 표지를 확인하며 주행해 주세요. |
| 급가속 횟수 | 급가속 `{count}`회가 기록됐어요. 가속 페달을 천천히 밟아 보세요. |
| 급감속 횟수 | 급감속 `{count}`건이 확인됐어요. 앞차와 거리를 충분히 두고 도로 상황을 미리 살펴보세요. |
| 가감속 공통 가점 | 급가감속 구간은 가점에서 제외됐고, 가감속 공통 가점은 `{points}`점이에요. |
| 방향지시등 위반·최종 감점 | 미사용·늦은 사용·반대 방향별 횟수와 합계 감점을 표시 |
| 회전 판정 불가 | 자료 부족으로 판정하지 않았다는 안내, 감점 없음 |

가감속 가점을 임의로 급가속/급감속 각각에 나누지 않는다. 급가감속을 건당 감점으로 표현하지 않는다. 판정 가능한 회전만 설명하고 차선변경 관찰은 위반 문장에서 제외한다. 구버전 기록은 저장 당시 채점 방식에 맞는 설명을 유지한다. 점수가 없으면 안전하게 운전했다고 단정하지 않는다.

추가 수정: 급가속·급감속 두 카드 내부에 같은 '가감속 공통' 가점을 표시한다. 이는 각각의 독립 가점을 합치는 것이 아니며, 한 번만 합산한다는 안내를 함께 표시한다. 대회 종료 시각과 같거나 이후 도착하면 시간 초과 실격이다. 종료 전 도착 후 주차가 늦어진 경우에는 실제 도착 시각으로 인정한다. 이번 변경 전에 저장한 기록의 원장이나 점수를 소급 변경하지 않는다.

최종 화면 수정: 사용자 요청에 따라 운전 습관 요약 네 카드의 가감점 수치·가점 제외 문구·공통 가점 안내·내부 구분선을 모두 제거했다. 카드에는 거리/횟수와 항목 설명만 남긴다. 점수 산정과 별도의 점수 상세 내역은 유지한다.

## 검증

최종 결과: core/app 단위 테스트 212개 통과, 에뮬레이터 13개 통과, debug APK·테스트 APK 빌드 성공. 현재 브랜치 APK를 설치하고 앱을 다시 열어 두었다.

시간 초과 실격 후속 수정 검증: 단위 테스트 214개 및 에뮬레이터 14개 통과. 실제 시연 주행을 마감 뒤 종료해 실격·점수 없음·배지/보상 없음·재실행 후 당일 참가 제한을 확인했다. 두 가감속 카드 내부의 공통 가점 표시도 화면 검사했다. 상단 요약 영역 높이 축소는 배치안만 제안했으며 이번 수정에는 포함하지 않았다.

- 단위 테스트: 일일 점수 대체 차단, 목적지와 무관한 하루 한 경기 보상, 문장 수치 치환, 차선변경 관찰 제외, 회전 자료 없음, 자정 경계 달력 필터.
- 에뮬레이터: `DailyParticipationTest` 4개, `DailyResultIntegrationTest` 3개, `BeltOutcomePersistenceTest` 6개.
- 실제 시연 주행 실행 → 95점 완료 → 새 배지 획득 → 경기·배지 보상 합산 → 상세 재조회 → 동일 종료 재호출 → 모델 재생성 후 재참가 차단.
- 실격 결과 저장 → 보상·배지 진행 없음 → 당일 재참가 차단 → 다음 날 참가 가능.
- 자정 전 예약 → 자정 후 완료 → 원래 참가일 진행률·지갑 키 유지.
- 테스트는 별도 저장 공간에서 실행하며 사용자 지갑·참가 내역을 초기화하거나 테스트 보상을 넣지 않는다.

실격 연동 시험은 저장 진입점에 실격 결과를 넣어 기록·보상 흐름을 확인한 것이다. 이번 시험을 실제 조수석 SDK 신호 또는 내장 내비/GPS 종단 검증으로 간주하지 않는다. 참가 제한은 현재 기기 로컬 저장 기준이며 여러 기기 통합 제한은 서버 작업에 포함해야 한다.

화면 캡처와 실행 로그는 로컬 `android/app/build/verification/daily/`에 보관한다. 문장 검사에서 발견한 Android 정규식 호환 문제는 정규식 없이 검사하도록 수정했으며, 자정 경계에서 달력은 도착일을 사용하던 문제를 참가일로 통일하고 회귀 테스트로 확인했다.
