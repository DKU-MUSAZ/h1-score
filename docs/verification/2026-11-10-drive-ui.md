## 발견 및 수정
- 기존 완료 알림은 !uiVisible일 때만 생성. AAOS 분할 창에서는 앱이 보이는 상태로 남을 수 있어 누락됨. 주차 완료 시 알림 생성으로 수정.
- 알림 PendingIntent에 결과 action을 지정하고 onCreate/onNewIntent에서 처리.
- 오래된 주차 상태 때문에 화면 전환이 거부되던 경로: 결과 화면 요청은 저장하고 실제 내용 노출은 기존 fresh parked gate를 유지.
- 프로세스 종료 후 결과가 사라지는 문제: 마지막 완료 결과 JSON 저장/복구 추가, 재보상은 하지 않음.
