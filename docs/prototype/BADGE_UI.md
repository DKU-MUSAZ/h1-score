# 월간 배지 컬렉션 UI

앱 왼쪽 **배지** 메뉴에서 확인합니다. 기존 안전점수와 포인트 지급 엔진은 변경하지 않는 UI 미리보기입니다.

## 디자인

GitHub 홈/결과 화면과 같은 H1Style 팔레트, 연한 회색 바탕, 흰색 목록 패널, 연회색 배지 카드, 네이비 요약 카드 및 동일한 둥근 모서리를 사용합니다. 공통 스타일은 `H1Style.kt`에 모았으며 기존 홈 화면 색상은 그대로 유지합니다.

모든 유형의 마스코트 뒤쪽 장식은 점수 유형에 쓰던 같은 방패 실루엣입니다. 유형별 아이콘과 포인트 색상은 유지하고, 길·원·달력·월계수 배경은 제거했습니다.

순위 마스코트는 한 손으로 트로피를 위로 들어 올립니다. 최종 트로피는 첫 한 손 시안 대비 약 200% 크기를 목표로 제작해 캐릭터 얼굴 가장자리와 일부 겹치더라도 트로피가 강조되도록 했습니다. 기존 금색 방패를 든 특별 포즈는 신규 배지 획득 연출용으로 유지합니다.

| 순위 배지 | 트로피 |
|---|---|
| 순위 첫걸음 / 순위 적응 완료 | 브론즈 |
| 중위권 돌파 / 꾸준한 상위권 | 실버 |
| 상위권 단골 | 골드 |
| 이달의 에이스 | 플래티넘 |

배지 카드 → 조건/진행률 상세 → 다음 목표 → 월간 보너스 → 교환권 목표를 연결합니다. 동일 트로피 등급은 카드·상세·다음 목표에서 일관되게 표시합니다.

## 생성 에셋

내장 `image_gen` 편집 모드로 원본 무사즈의 얼굴·복장·로고를 참조해 제작했습니다. 원본 파일은 덮어쓰지 않았습니다. 투명 RGBA PNG 4종이며 Android 런타임 경로는 다음과 같습니다.

- `android/app/src/main/res/drawable-nodpi/musaz_trophy_bronze_raised_large.png`
- `android/app/src/main/res/drawable-nodpi/musaz_trophy_silver_raised_large.png`
- `android/app/src/main/res/drawable-nodpi/musaz_trophy_gold_raised_large.png`
- `android/app/src/main/res/drawable-nodpi/musaz_trophy_platinum_raised_large.png`

최종 프롬프트 전체는 `sources/musaz-raised-trophy-prompts.json`에 보관합니다. 공통 지시: 한 손으로 올려 든 트로피만 첫 한 손 시안 대비 약 2배 확대, 얼굴 일부 겹침 허용, 캐릭터 정체성/흰 민트 안전모/남색 HYUNDAI 티셔츠 유지, 배경은 투명. 재질은 브론즈·실버·골드·플래티넘으로 구분합니다.

## 구성

- 참여 4종, 점수 5종, 순위 6종, 꾸준함 3종: 총 18종.
- `달성 예시 보기`를 켜면 참여 12일 등의 일관된 예시 기록이 네 유형에 함께 반영됩니다. 예시 배지 보너스 1,750P(주간 루틴 3회 포함), 대회 보상 예시 1,500P, 합산 예시 잔액 3,250P입니다.
- 기본 화면은 월간 실적을 임의로 추정하지 않고 0으로 표시합니다. 월간 이력/서버 집계 연결은 별도 작업입니다.
- 보상 규칙 팝업에 하루 1회, 월간 배지 보너스 최대 4,000P, 대회 상위 10% 별도 500P, 공동 순위/최소 인원, 주간 집계 규칙을 안내합니다.
- 엔진오일 교환권은 목표 50,000P로 표시하되 실제 제휴 전임을 안내하며 교환/발급 버튼은 제공하지 않습니다.
- 기존 보유 배지는 `이전 배지`에서 확인할 수 있습니다. 실제 잔액, 과거 배지와 지급 내역은 바꾸지 않습니다.
- 기존 주차 상태에 따른 화면 접근 제한을 유지합니다.

## 구현 파일

`BadgeCollectionScreen.kt`에 배지 목록, 공통 엠블럼, 카드, 탭, 진행률 및 상세/보상 안내를 구성했습니다. `H1App.kt`의 배지 메뉴가 이 화면을 엽니다.

`BadgeCollectionUiTest`는 주차된 시연 상태로 유형 전환, 상세 조건, 보상 안내, 예시 끄기 및 기존 잔액/배지 불변을 검사합니다. 이미지 산출물은 에뮬레이터에서 앱 뷰를 렌더링한 결과이며 차량 센서 검증용이 아닙니다.

배경 통일 보완: 홈 지도에만 쓰이는 그라데이션을 배지 목록에서 제거했습니다. 결과 화면의 흰색 24dp 패널, 마일리지 화면의 네이비 요약 카드, 16dp 보조 카드/탭, 제목 32sp·설명 14sp 규칙에 맞췄습니다. 배지 원본과 트로피 이미지는 유지합니다.
