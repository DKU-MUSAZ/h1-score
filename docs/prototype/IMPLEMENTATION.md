# 구현 범위와 기술 연결

2026-11-05 · 0.2.0-prototype

## 구조와 버전

`core`는 순수 Kotlin으로 참가 상태·점수·순위·지급 한도·배지·표정 구간을 계산한다. `app`은 Compose 화면, 앱 수명 동안 유지되는 모델, Pleos/AAOS 어댑터, 로컬 저장을 담당한다. 사용자 동의로 시작한 기록은 foreground service로 내비게이션 앱 사용 중에도 유지하도록 구성했다.

| 구성 | 버전 / 역할 |
| --- | --- |
| Android Studio | Rabbit 2 / 2026.2.2 |
| Gradle / AGP | 8.11.1 / 8.9.2 |
| Kotlin / Compose BOM | 2.1.20 / 2025.04.01 |
| JDK | 21.0.7, 앱 바이트코드 JVM 17 |
| Android | compile 35 / target 34 / min 28 |
| Pleos 에뮬레이터 | Connect 2.1.0, API 34, ARM64, 1920×1080 |
| Vehicle | ai.pleos.playground:Vehicle:2.3.2 |

SDK는 공식 Maven 저장소 `https://nexus-playground.pleos.ai/repository/maven-releases/`에서 받았다. 사용 권한 선언과 실제 기기의 Capability를 확인하며, 없는 데이터를 실제 값처럼 합성하지 않는다.

SDK 연결과 실제 주행 전 과정 검증은 구분한다. 연결 화면과 수신 로그가 이번 구현의 증거이며, 실차·도로 검증이나 시장 심사 통과를 의미하지 않는다.

## 참가·평가

- 출발 전에 정차 상태에서 동의·예약한다. 남은 경로가 10km 이하가 되는 첫 시점부터 기록한다. 주행 중 수락 팝업을 누르도록 하지 않는다.
- 처음부터 10km 미만이면 바로 개인 기록을 시작한다. 순위/M 대상이 아니다.
- 10km 경계를 여러 번 통과해도 시작은 한 번이다. 목적지가 달라지거나 안내가 취소되면 기존 세션을 종료한다.
- 도착만으로 결과를 공개하지 않는다. P단·속도·차량 화면 제한을 함께 확인한다.
- 속도/제한속도 누락, 2.5초를 넘는 샘플 간격, 비정상 값은 제외한다. 신선도는 속도 2.5초, 목적지 10초, 제한속도 120초다.
- 개인 점수는 유효 거리 500m 이상 및 커버리지 90% 이상에서 표시한다. 순위는 9km 이상 및 90% 이상이 필요하다.

제한속도 SDK가 변경 시에만 알리는 환경에서는 120초 만료가 정상 데이터를 지나치게 제외할 수 있다. 실제 도로 링크와 갱신 의미를 확인해 수정해야 한다.

## 주행습관 점수 v0.2 · 60점 시작 가점제

- 시작점수 60점 + 제한속도 준수 최대 25점 + 부드러운 가감속 최대 15점입니다.
- 실제 측정 이동거리를 1km 구간 10개로 나눕니다. 각 구간은 제한속도 준수 거리/1000 × 2.5점, 제한속도를 준수하면서 가속도가 −2.5~+2.5m/s²인 거리/1000 × 1.5점을 얻습니다.
- 급가속 >+2.5m/s² 또는 급감속 <−2.5m/s²인 구간은 부드러운 가감속 가점을 얻지 못합니다. 별도 급제동 감점은 없습니다. 가감속 가점은 제한속도를 지킨 구간에서만 부여합니다.
- 1km가 덜 채워진 구간도 주행한 거리만큼 비례 가점입니다. 짧은 주행을 10km 만점으로 환산하지 않습니다. 1km 정상 주행 64점, 5km 80점, 10km 100점입니다.
- 샘플 간 평균 속도 × 시간으로 거리를 계산합니다. 제한속도 경계는 선형 속도 보간으로 분리하고 1km 경계도 나눠 배분합니다. 최초 10km 이후에는 더 이상 점수를 쌓지 않습니다.
- 속도는 정상이나 제한속도가 누락된 구간은 구간 거리를 차지하지만 가점은 없습니다. 이후 추가 주행으로 누락 구간을 채우지 못합니다.
- 개인 점수 표시의 500m·커버리지 90%, 순위 유효성의 9km·90% 기준은 유지합니다. 초기 샘플이 전혀 없을 때만 시작값 60을 제공합니다. 측정값이 있지만 모두 누락이면 점수 미산출입니다.
- 계산은 소수점을 유지하고 최종 정수 점수 표시 시 반올림합니다. 40점의 가점을 모두 얻기 전에는 100점 표시를 하지 않습니다.
- 진행 화면은 시작 60점과 누적 가점을 표시합니다. 주차 후 결과에서 항목별 총 가점과 1km별 내역을 열어볼 수 있습니다.
- 이 산식과 급가감속 기준은 팀의 시제품 정책이며 검증된 사고위험 모델이 아닙니다.

## 안전벨트 실격

실제 모드에서 참가 전 운전석 벨트 조건을 충족해야 합니다. 예약 또는 기록 중 신선한 미착용 상태가 수신되면 DISQUALIFIED로 전환합니다. 현재 세션의 점수·순위·마일리지·배지는 지급하지 않으며 재착용하더라도 해당 세션은 복구되지 않습니다. 완료된 과거 기록은 유지합니다.

센서 미수신이나 오래된 값은 미착용으로 단정하지 않습니다. 기록 중 벨트 상태가 확인되지 않는 샘플은 점수 입력에서 제외하여 데이터 충족률에 반영합니다. 시연 모드는 가상 벨트 조건이며, 실제 차량 센서로 인한 실격 검증은 별도입니다. 에뮬레이터 경고등 보조 판정은 디버그 환경에서만 사용합니다.

## M·배지

완료 보상 0M. 유효 기록이고 85점 이상이면 정해진 순위 슬롯을 지급한다. 3인 60/20/0, 4인 80/40/20/0, 5인 100/60/30/0/0M. 동점자는 차지한 슬롯 합계를 인원으로 나눈 정수 몫을 받는다. 도착 시간으로 동점을 가르지 않는다.

동일 세션 중복 지급, 동일 목적지 하루 2회 지급, 전체 하루 3회 지급을 로컬 원장에서 차단한다. 실제 서비스의 서버 원장·위변조 방지 기능을 대신하지 않는다.

현재 배지는 첫 유효 평가, 해당 목적지 첫 유효 방문, 85점 이상 TOP 3다. 소유 ID로 중복 발급을 막고 실제/시연 모드를 분리한다. 연속 일수/5회 배지는 준비 중이다. 방패를 든 무사즈는 신규 `BadgeCelebration`에서만 사용한다.

## 저장·제약

잔액·정산 ID·일일 한도·소유 배지 ID는 기기 SharedPreferences에 저장한다. 원시 샘플, 현재 세션, 최근 보고서, 아직 열어보지 않은 배지 안내는 프로세스 메모리에 있다. OS가 프로세스를 종료하면 진행 기록은 복원하지 않는다. 이미 지급한 배지/M은 중복 지급하지 않는다.

외부 서버로 위치·주행 데이터를 보내는 기능은 없다. 사용자 매칭·순위 공유, 쿠폰 교환, 서버 정산, 음성 수락은 후속 구현이다.

## GPS 회전·방향지시등 정책 (시제품)
- 최종 점수 = clamp(60 + 속도 가점 + 가감속 가점 − 회전 감점, 0, 100). 반올림은 마지막에만 합니다. 점수는 감점으로 60 미만이 될 수 있습니다.
- 미사용 −1점, 반대 신호 −2점, 주행당 감점 상한 10점. 하나의 회전에는 하나의 판정만 적용합니다. 정확한 신호 이력이 하나라도 있으면 보수적으로 일치 처리합니다.
- NaviHelper.onTBTInfo의 첫 안내가 일반/급격한 좌·우회전이고 40m 이내, 안내가 3초 이내일 때만 회전 후보를 만듭니다. 나들목·유턴·회전교차로·차로 변경은 평가하지 않습니다. 안내는 도로 형태 전체를 대신하지 않으므로 이 판정 역시 휴리스틱입니다.
- 직전 중립 각도 ≤2°, 시작 앞바퀴 조향각 ≥5°(왼쪽 음수), 같은 방향 조향 0.5초 이상. 중립 복귀를 1초 유지하면 종료, 종료 후 3초 중복 방지. 최대 관측 시간 20초. 반대 조향·불완전 회전은 판단 보류입니다.
- GPS 진입/종료 이동 방향 차이가 회전 방향으로 35~135°, 위치 변위 ≥15m여야 합니다. 전진 D단, 속도 2~25m/s만 평가합니다.
- Android LocationManager GPS_PROVIDER를 이용합니다. 위치 정확도 ≤10m, 이동방향 정확도 ≤15°, 위치·조향·신호 신선도 ≤1.5초가 필요합니다. 데이터 공백 >1.5초, 미확인 신호, 부족한 정확도에는 감점하지 않습니다.
- 조향 전 최대 3초부터 회전 종료까지의 방향지시등 이력을 확인하므로 자동 취소된 신호도 인정합니다. ‘사전 신호 사용 시간’에 대한 법규 판정은 아닙니다.
- 첫 10km 안에 완결되고 점수 입력 시간 범위 안에 있는 회전만 반영합니다. 미완료 회전은 감점하지 않습니다. 세션 시작마다 상태를 초기화하며 벨트 상태 미확인 시 진행 중 회전 판정을 중단합니다.
- Vehicle 2.3.2 조향/신호 값을 250ms 주기로 요청합니다. 실제 전달 주기는 SDK/차량에 따라 달라지며 요청 주기가 보장된 센서 주기는 아닙니다. GPS·신호·조향 시각은 elapsedRealtime으로 통일합니다.
- NaviHelper 제한속도는 마지막 수신 후 2.5초까지 인정합니다. 제한속도 미수신 구간은 가점이 없습니다.
- 정확한 위치 권한을 요청하고 기록 서비스를 location foreground service로 실행합니다. 권한 거부 시 속도·가감속 기록은 유지하되 GPS 회전 감점은 보류합니다. 위치를 별도 서버로 업로드하거나 저장하지 않습니다.
- 모든 수치는 에뮬레이터 검증을 위한 초기 정책입니다. 실제 도로·차종별 조향 특성·지도 안내 품질로 추가 검증해야 합니다.
