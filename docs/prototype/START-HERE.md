# 안운잘부 처음부터 끝까지 실행하기

프로젝트: `android/` · 앱: 안운잘부 · 버전: 0.2.0-prototype

## Android Studio

1. Android Studio에서 이 폴더의 `android` 프로젝트를 연다.
2. 상단 실행 기기를 **H1 Pleos**, 실행 구성을 **app**으로 선택한다.
3. 초록색 실행 버튼을 누른다. 최신 코드를 빌드해 에뮬레이터에 설치한다.
4. 앱 화면이 보이지 않으면 **View → Tool Windows → Running Devices**를 연다. 별도의 Dock 버튼을 찾을 필요는 없다.
5. 화면이 너무 작으면 Running Devices의 **Actual size / 100%**를 사용한다. macOS 도구 창 최대화 단축키는 `⌘⇧'`다.

2026-11-06 에뮬레이터에서 참가 예약 → 압축 주행 → 주차 → 92점 결과 → 신규 배지 표시를 직접 확인했다. 최종 검증 범위는 QA.md에 기록한다.

화면 왼쪽 자동차·벨트 안내는 Pleos 시스템 영역이고, 안운잘부는 오른쪽 영역이다. 앱은 Pleos 연결 모드로 시작하며, 홈 지도 마커에서 참가를 시작한다. 시연하려면 오른쪽 위 **Pleos 연결 → 시연 모드 켜기**를 선택한다. 현재 구현은 **주차 중 미리 참가하고 마지막 10km에서 자동 기록**하는 흐름이다. 주행 중 10km 지점에서 띄우는 수락 알림은 이번 시제품에 포함하지 않았다.

## 기본 시연: 30초 안팎

1. 오른쪽 위 **Pleos 연결 → 시연 모드 켜기**를 선택한다.
2. 챌린지 검색창을 열고 **여의도 한강공원**, **현대 모터스튜디오 고양**, **단국대학교 죽전캠퍼스** 중 한 곳을 선택해 예약한다. 여의도 기본 예시의 초기 남은 거리는 14km다.
3. 예약 화면에서 **시연 주행 재생**을 누른다.
4. 남은 거리가 10.0km가 되면 기록이 한 번 시작된다. 주행 중에는 다른 메뉴·순위·배지를 열 수 없다.
5. 도착 후 잠시 주차 대기를 거쳐, 가상 P단 상태에서 결과가 열린다.
6. 점수 근거와 가상 순위, 지급 M을 확인한다. 여의도 기본 예시는 5인 순위다.
7. 금색 **새 배지 …개가 도착했어요 → 열어보기**를 누른다. 이때만 방패를 든 무사즈가 등장한다. **다음 배지 보기 / 좋은 순간으로 간직하기**으로 닫는다. 이미 받은 배지는 다시 지급하지 않는다.
8. 왼쪽 **내 기록**에서 방금 주행을 다시 연다. **마일리지**에서 잔액과 정비 혜택 예시를 확인한다. **배지**에서 획득 상태를 확인한다.
9. 다시 해보려면 왼쪽 **챌린지**로 돌아가 검색창에서 시연 스팟을 선택한다.

기본 축하 시나리오는 92점·공동 1위이며, 한도에 걸리지 않은 첫 보상은 80M이다. 도착 속도에는 가점이 없다. 오늘 검수하면서 이미 획득한 배지와 M은 보존되어 있으므로 이 Mac에서 다시 돌리면 신규 배지나 추가 적립이 없을 수 있다.

시연은 압축 재생이다. 화면 0.7초마다 실제 시간 1초 간격으로 만든 샘플 24개를 평가 엔진에 넣는다. 이 재생 속도를 실제 SDK 수집 빈도로 설명하면 안 된다.

## 다른 표정 보기

주차 중 상단 **시연 모드**를 누른다. `다음 시연의 결과 표정`에서 축하 / 응원 / 울먹임을 선택하고 다음 주행을 시작한다. 점수를 직접 고정하는 방식이 아니라 다른 샘플을 같은 평가 엔진에 넣는다.

| 선택 | 완주 후 표시 |
| --- | --- |
| 축하하는 무사즈 | 90점 이상, 환하게 축하하는 표정 |
| 응원하는 무사즈 | 75~89점, 다정한 응원 |
| 울먹이는 무사즈 | 75점 미만, 작은 눈물과 다음 운전 제안 |

`우리 동네 공원`은 3.2km 개인 기록이다. 순위와 M은 지급하지 않는다. 현재 새 배지 지급은 유효 9km 평가 조건을 만족한 기록에 적용한다. 짧은 이동용 배지 조건은 후속 설계 항목이다.

한국시간 기준 하루 한 경기만 참가한다. 참가 확정 후 취소·실격·확인 불가도 당일 참여에 포함한다. 실제/시연 참가 내역은 분리하며 앱 데이터는 시연을 위해 자동 삭제하지 않는다. 경기 보상과 배지 보상은 구분해 한 번씩 적립한다.

## 첫 설치 상태로 다시 체험하기

단순한 재실행은 배지·M을 유지한다. 처음부터 배지 3개를 여는 발표를 반복하려면 **에뮬레이터의 안운잘부 앱 데이터만 초기화**하면 된다. 그 에뮬레이터의 가상 잔액·획득 배지가 지워지므로 필요할 때만 한다.

Android Studio Terminal에서 아래 명령을 실행한 후 초록 ▶ 버튼으로 앱을 다시 실행한다. 에뮬레이터 전체 Wipe Data는 필요 없다.

```sh
/Users/ziuuu/Library/Android/sdk/platform-tools/adb -s emulator-5554 shell pm clear ai.musaz.h1score
```

`Success`가 나오면 해당 앱의 로컬 데이터가 초기화된 것이다. 이는 사용자가 원할 때 직접 수행하는 선택 사항이며 검수 중에는 실행하지 않았다.

## 내장 내비로 목적지 검색하기

1. P단에서 홈 지도에 ‘한강’을 검색한다.
2. 여의도 한강공원 마커를 선택하고 운전석 벨트를 착용한 뒤 **동의하고 내비 시작**을 누른다.
3. 음성을 듣고 싶으면 출발 전에 오른쪽 위 모드 버튼 → **무사즈 음성 안내**를 켠다.

## 실제 SDK 확인

주차 중 **시연 모드 → SDK 연결 상태 보기**에서 실제 응답을 확인한다. 이 화면의 값은 시연 입력과 별도다.

실제 입력 전환에는 기기의 P단·속도 0·화면 제한 해제가 필요하다. 참가에는 운전석 벨트와 신선한 내비 목적지 정보도 필요하다. 유효 제한속도가 없어도 임의의 값을 넣지 않는다.

실제 모드의 목적지 주행·점수·정산 전체를 검증한 상태는 아니다. 실제 서버 매칭이 없어 개인 결과만 지원한다.

## 개발 명령

JDK 21과 Android SDK가 필요하다. 이 Mac의 Gradle JDK는 Microsoft OpenJDK 21.0.7로 설정했다.

```sh
cd android
./gradlew :core:test :app:assembleDebug :app:lintDebug
```

화면이 안 열리면 Android Studio 상단 메뉴 **Run → Run app**을 사용한다. 에뮬레이터가 키보드를 잡고 있을 때는 단축키가 기기로 전달될 수 있다. 화면 버튼을 직접 클릭하는 것이 가장 간단하다.

SDK 위치는 각 컴퓨터의 `local.properties`에서 설정한다. 팀 공유 압축에는 개인 SDK 경로·캐시·Android Studio 작업창 상태를 포함하지 않는다.

## 발표에서 설명할 문장

“안운잘부는 같은 목적지의 운전자들이 마지막 접근 구간의 주행습관을 비교하고, 주차 후 피드백과 정비 혜택을 위한 마일리지를 받는 차량 앱입니다. 이번 시제품은 실제 Pleos SDK 연결과 점수 엔진을 구현했고, 다른 참가자·보상은 시연 데이터로 구성했습니다.”

### 내비와 나란히 보기

Pleos 시스템이 두 앱을 동시에 배치할 수 있는 환경에서는 내장 내비와 안운잘부를 각각 연다. 안운잘부 창이 좁아지면 목적지, 거리, 기록 상태 중심의 좁은 창 화면을 사용한다. 앱이 시스템 분할을 강제로 켜거나 내장 지도 화면을 앱 안에 복제하지는 않는다.

홈 지도에서 참가에 동의하면 안운잘부가 내장 내비에 목적지 경로를 요청한다. 참가 현황은 시연 값이다.

최종 확인 항목: 실제 내비 검색 열기, 두 앱 분할 배치, 두 목적지 간 카드 전환. 빌드와 설치 검증과는 별도로 확인한다.


### 마일리지 사용 확인

**마일리지 → 차량 관리 혜택**에서 필요 금액, 진행 막대, 부족한 금액을 확인한다. 시연 잔액이 80M 이상이면 와이퍼 교환 상세를 열고 **80 M으로 시연 교환**을 누른다. 잔액이 80M 줄고 교환 완료로 표시되며, 같은 혜택의 재교환은 막는다. 필터 300M, 엔진오일 600M은 시연 가격이다. 실제 쿠폰이나 결제는 연결하지 않았다.

홈 오른쪽 챌린지 지도는 한강을 단순화한 시연 지도다. 여의도한강공원 참가 예시는 4명이며, 마감까지 남은 시간은 한국 시간 자정 기준으로 갱신한다. 원을 누르면 참가 확인창이 열린다. 벨트가 열려 있으면 확인창에 조건이 표시되고 내비 시작 버튼이 비활성화된다.

### 챌린지 지도에서 바로 참가하기

홈 지도에서 ‘한강’ 또는 ‘여의도’를 검색하고 +/−로 시연 지도를 조절한다. 여의도한강공원 원형 마커 → 참가 확인 → **동의하고 내비 시작**을 누른다. 실제 입력 모드에서는 P단과 운전석 벨트 상태를 확인한 뒤 내장 내비에 해당 좌표의 경로를 요청한다. 목적지와 유효한 거리가 돌아와야 세션을 시작하며, 10km 이상으로 예약된 주행은 마지막 10km 진입 시 자동 기록한다. 10km 미만 경로는 개인 기록이다. 검색은 현재 등록된 챌린지 장소 대상으로 동작한다.

에뮬레이터 자동 검증: 시연 UI E2E(검색, 확대/축소, 참가 동의, 10km 기록, 결과)와 실제 NaviHelper 경로 요청 테스트(여의도한강공원, 남은 거리 22km 수신)를 각각 통과했다. 실제 차량 입력으로 10km 진입부터 도착까지는 별도 검증이 필요하다.

홈 검색에 등록 챌린지가 없으면 **내비에서 검색**으로 검색어를 보낸다. 내비 결과에서 장소를 선택하면 일반 길 안내를 이용할 수 있다. 챌린지 참가 확인창에서 벨트 조건이 충족되지 않았을 때는 **길 안내만 열기**로 여의도한강공원 경로를 요청할 수 있다.

### 홈에 실제 카카오맵 표시하기

1. [카카오디벨로퍼스](https://developers.kakao.com/console/app)에서 앱을 만들고 **카카오맵 → 사용 설정 → 상태 ON**으로 설정한다.
2. **앱 → 플랫폼 키 → 네이티브 앱 키 → Android 앱 정보**에 패키지명 `ai.musaz.h1score`와 이 Mac의 디버그 키 해시 `fCIioNy4O2QZ6tjtDhy+Ruffl/Q=`를 등록한다. 다른 Mac이나 배포용 서명은 해당 빌드의 키 해시를 등록한다.
3. `android/local.properties`의 기존 SDK 경로 설정 아래에 `KAKAO_NATIVE_APP_KEY=발급받은_네이티브_앱_키`를 한 줄 추가하고 Android Studio에서 ▶로 다시 실행한다.
4. 홈의 **카카오맵** 표시와 여의도 한강공원 마커를 확인한다. 마커를 누르면 기존 참가 확인창이 열린다. 인증이나 지도 로딩 오류가 발생하면 시연 지도로 돌아간다.

공식 설정은 [카카오맵 사용 설정](https://developers.kakao.com/docs/ko/kakaomap/common)과 [Android SDK 시작하기](https://apis.map.kakao.com/android_v2/docs/getting-started/quickstart/)를 참고한다.

## 회차 동의와 결과 복귀

회차는 한국 시간 기준입니다. 평일은 새벽 00:00–07:00, 출근 07:00–10:00, 주간 10:00–17:00, 퇴근 17:00–20:00, 야간 20:00–다음 날 00:00입니다. 주말은 00:00–08:00, 08:00–16:00, 16:00–다음 날 00:00으로 나눕니다. 지도에서 여의도 한강공원 마커를 누르고 마감과 목적지 조건에 체크하면 참가 버튼이 활성화됩니다. 실제 모드에서는 회차가 열려 있어야 합니다. 도착 시각이 마감 시각과 같거나 그 이후라면 순위와 마일리지에서 제외됩니다. 주차는 결과를 여는 조건입니다.

내장 내비에 길 안내 중인 목적지가 있다면, 한강 챌린지 기준점에서 직선거리 1km 이내일 때 **현재 목적지로 참가**를 선택할 수 있습니다. 시제품의 다른 참가자와 순위는 시연 데이터입니다.

1. **시연 모드**에서 마커 → 마감 조건 동의 → **참가 예약 · 내비 시작**을 누릅니다.
2. 내장 내비가 여의도 한강공원 길 안내를 시작하면 Pleos 하단 **H1** 앱 아이콘으로 돌아와 **시연 주행 재생**을 누릅니다.
3. 백그라운드 복귀도 확인하려면 재생 직후 하단 내비 아이콘을 누르고 약 30초 기다립니다. 시스템 알림에서 **안운잘부 주행 결과가 준비됐어요 → 결과 보기**를 선택합니다. 알림 권한을 주지 않았다면 Pleos 앱 목록이나 하단 안운잘부 아이콘에서 앱을 다시 열면 됩니다.

실제 입력 모드에서는 시연 재생 단계 대신 NaviHelper 목적지 도착 콜백과 차량의 P단·정차 상태로 결과를 준비합니다. 내비의 **안내 종료** 버튼은 경로 취소입니다.

- [Pleos NaviHelper](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/intro)
- [현대자동차그룹 공모전 개발 환경](https://appdevchallenge.auto-hmg.io/guide/development)

[시연 영상](demo-result.mp4)에는 여의도 한강공원 참가와 시연 모드의 92점·공동 1위 결과가 담겨 있습니다. 녹화 음성은 무음입니다. 시연 중 10km 진입 안내는 Pleos 음성 엔진의 재생 완료 로그로 확인했습니다. 실제 입력 테스트에서는 에뮬레이터 GPS가 여의도에 도달한 뒤에도 내장 내비가 22km를 보고해, 실제 입력에 따른 10km 진입과 도착 후 결과 복귀는 검증하지 못했습니다.
