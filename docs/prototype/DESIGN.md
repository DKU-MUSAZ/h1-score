# H1-score 화면과 MUSAZ

2026-11-05 · 운전 중에는 조용히 기록하고, 도착한 뒤 따뜻하게 피드백하는 방향.

## 확인한 레퍼런스

| 공식 레퍼런스 | 확인한 범위 | 반영한 것 |
| --- | --- | --- |
| [Finch](https://finchcare.com/) | 공식 소개의 캐릭터·습관 피드백 | 친근한 동반자, 비난하지 않는 피드백, 감정을 전달하는 무사즈 |
| [Strava Challenges](https://business.strava.com/challenges) | 공식 챌린지 흐름과 완료·보상 단계 화면 | 참가 → 활동 → 완료 → 보상 분리, 결과를 이해한 뒤 성취 열기 |

구조와 표현 방식만 참고했다. 로고·캐릭터·UI 자산을 복사하지 않았다. TMAP 페이지는 연결 화면만 확인되어 시각 디자인 근거로 사용하지 않았다.

## 시각 기준

| 역할 | 값 | 쓰임 |
| --- | --- | --- |
| Ink | #152D4C | 티셔츠와 이어지는 제목·버튼·주행 화면 |
| Paper | #F5F6F8 | 넓은 여백, 카드 밖 배경 |
| Green | #176B54 | 안전한 흐름·강조 텍스트 |
| Mint | #74DFB2 | 안전모 띠와 연결된 진행 표시 |
| Ice | #EAF2F7 | 홈의 도로·무사즈 무대 |
| Gold | #BC8624 | 새 배지 획득 순간 |

기기 기본 한글 고딕으로 Pleos의 기본 서체와 연결했다. 홈 제목 43sp, 결과 제목 29sp, 주요 본문 14~17sp. 가로 1180×680 논리 캔버스를 창에 비례 배치한다. 다양한 비율·글자 확대의 출시 수준 검증은 남아 있다.

홈의 기억할 요소는 큰 무사즈와 도로 곡선이다. 나머지는 목적지·평가 구간·참가 버튼 순서로 배치한다. 주행은 네이비 화면과 최소 상태만 보여주며 순위·캐릭터·배지 조작을 숨긴다.

## 화면별 역할

| 화면 | 사용자의 일 | 구성 |
| --- | --- | --- |
| 홈 | 참가 결정 | 목적지, 10km 안내, 응원 무사즈 |
| 참가 | 기록/보상 이해 | 수집 정보, 시작 시점, 주차 후 공개, 동의 |
| 예약·주행 | 상태 확인 | 남은 거리, 자동 시작, 조용한 경로 모티프 |
| 결과 | 점수와 개선점 이해 | 점수, 표정, 구체적인 한 줄, 두 지표 |
| 그룹 결과 | 비교와 M 확인 | 시연 표시, 순위, 실제 적립량 |
| 새 배지 | 이번 성취 열기 | 새 제목과 방패 무사즈. 신규 획득 때만 |
| 컬렉션 | 쌓인 기록 확인 | 일반 응원 무사즈, 획득·잠금 상태 |
| 마일리지 | 활용 경험 이해 | 가상 잔액, 제휴 전 정비 혜택 예시 |

## 표정 자산

| 상황 | 자산 |
| --- | --- |
| 홈 / 컬렉션 / 75~89점 | musaz-encourage.png |
| 90점 이상 | musaz-celebrate.png — 방패 없음 |
| 75점 미만 | musaz-sad.png — 작은 눈물 |
| 점수 미산출 | 기존 중립 안내 포즈 |
| 신규 배지 열기 | musaz-04-achievement.png — 금색 방패 |

표정 구간은 UX 시연 기준이며 안전 등급이 아니다. 낮은 점수에서도 벌점·조롱 문구를 쓰지 않고 개선 한 가지만 제안한다. 주행 중 울먹임이나 보상 애니메이션으로 관심을 끌지 않는다.

배지를 옷에 붙이지 않는다. 기존 네 포즈는 원본 두 장, 새 세 표정은 개별 투명 PNG다. 리깅·스켈레톤·3D 모델 파일은 없다.

## 시각 검수 상태

새 투명 캐릭터가 실제 Pleos 에뮬레이터 홈에 표시되는 것을 확인했다. 이후 결과 카드 여백과 중립 표정 분기를 보정했다. 최종 결과·배지 대화상자 직접 검수는 Mac 잠금으로 완료하지 못했다. 자동 테스트가 시각 검수를 대신하지는 않는다.

## 내비 연결 화면 참고 사례

- [차량 내장 Google Maps](https://support.google.com/maps/answer/9770907?hl=en): 목적지 검색과 경로 안내를 시스템 내비에 맡기는 흐름.
- [Strava 그룹 챌린지](https://support.strava.com/en-us/articles/15401736-how-do-group-challenges-work-on-strava): 참가 여부와 진행 상황을 같은 챌린지 맥락에서 보여주는 구성. H1-score의 순위는 주차 후 공개한다.
- [Waze 음성 안내](https://support.google.com/waze/answer/10264825?hl=en): 말수를 줄이고 운전 중 핵심 사건에만 짧은 음성을 사용한다.
- [Pleos NaviHelper](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/NaviHelper/intro), [Pleos TTS](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/TextToSpeech/intro): 내비 경로 읽기와 온디바이스 음성.
