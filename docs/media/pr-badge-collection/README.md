# 배지 컬렉션 개편 화면

앱 코드 `5ded177` 기준으로 Pleos 에뮬레이터에서 확인한 화면이다. 이미지에 표시된 진행률은 시연 또는 UI 검증용 기록이며, 실제 서버 순위를 수신한 결과가 아니다.

| 파일 | 확인 내용 |
|---|---|
| filters-attendance.png | 전체·출석 도장·명예 훈장·스팟 투어 필터와 신규 출석 마스코트 |
| honor-tier-lock.png | 브론즈 3종 및 브론즈 3개 획득 전 실버 잠금 안내 |
| honor-preview.png | 달성 예시보기에서 브론즈 완료와 실버 획득 가능 상태 |
| honor-guide.png | 순위 기반 획득 조건·개별 마일리지·실제 순위 연동 준비 상태 |

출석 도장 이미지는 수첩·도장 소품을 공유하면서 6종의 포즈를 달리했다. 명예 훈장은 기존 티어별 트로피 자산을 유지한다. 달성 예시보기는 화면만 바꾸며 실제/시연 마일리지 원장에는 적립하지 않는다.

## 운전석 안전벨트 실격 예시

`driver-belt-disqualified.png`는 운전석 실격 예시 1건을 추가한 앱을 Pleos 에뮬레이터에 설치하고, 시연모드의 내 기록에서 잠실종합운동장을 눌러 캡처한 실제 앱 화면이다. 캡처일은 2026-11-14이며 예시 기록 날짜는 4일 전인 2026-11-10이다.

화면은 운전석 안전벨트 미착용 사유, 점수·순위 미산정, 마일리지·배지 적립 제외 및 당일 참여 인정 안내를 보여준다. 이 이미지는 시연 기록의 표시를 확인한 자료이며, 콘솔에서 차량 신호를 주입해 실격을 발생시킨 검증 자료는 아니다. 예시 데이터는 읽기 전용이며 실제 기록과 보상 원장을 변경하지 않는다.
