# 배지 필터 통합과 출석 도장 이미지

## 확정 설계
- 필터: 전체 / 출석 도장 / 명예 훈장 / 스팟 투어.
- 출석 도장: join-5, join-10, join-15, join-20, routine-week, routine-month.
- 명예 훈장: 안전점수 5종, routine-score, 기존 랭킹 6종. 랭킹 티어 구분과 트로피 자산은 유지한다.
- 스팟 투어: 기존 장소 배지 3종. 환영 배지는 전체에서 유지한다.
- 획득 ID, 진행률 계산, 조건, 마일리지와 지급 로직은 변경하지 않는다. 화면 분류만 별도로 매핑한다.
- 출석 마스코트 6종은 기존 캐릭터를 기준으로 출석 수첩·도장 소품을 공유하고 포즈를 달리한다. 신규 자산은 별도 이름으로 저장한다.

## 구현 계획
1. 화면 분류를 추가하고 필터·목록·상세·안내를 함께 통합한다. 혼합된 명예 훈장에서 순위 배지만 연동 준비 상태를 표시한다.
2. 출석 도장 이미지를 각각 생성하고 저장·연결한다. 기존 랭킹 이미지 연결을 비교한다.
3. 기존 배지 UI 검증을 새 필터에 맞게 갱신한다. 단위 테스트·빌드와 가능한 에뮬레이터 검증으로 분류, 안내, 보상 유지 여부를 확인한다.

## 진행
- 설계: 사용자 승인한 분류 및 이미지 방향을 반영함.
- 구현: 화면 분류만 별도로 추가해 출석 6종 / 명예 12종 / 스팟 3종을 통합했다. 기존 조건·ID·진행률 함수·랭킹 정의를 이전 커밋과 비교해 일치함을 확인했다.
- 이미지: 내장 이미지 생성 도구로 투명 배경 1254×1254 PNG 6종을 제작하고 musaz_attendance_* 자산으로 연결했다. 프롬프트는 output/imagegen/attendance-stamps-v1.prompts.md에 보관했다.
