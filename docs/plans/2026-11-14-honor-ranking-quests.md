# 명예 훈장 12종 순위 퀘스트 전환

이 설계는 앞선 필터 통합 문서의 ‘안전점수 배지를 명예 훈장에 함께 표시한다’는 규칙을 대체한다. 출석 도장 6종, 스팟 투어 3종과 환영 배지는 유지한다.

## 확정 조건

| 티어 | 배지 | 달성 조건 | 마일리지 |
|---|---|---|---:|
| 브론즈 | 순위 첫걸음 | 상위 90% 이내 5일 | 5M |
| 브론즈 | 차분한 출발 | 상위 80% 이내 5일 | 10M |
| 브론즈 | 순위 적응 완료 | 상위 80% 이내 10일 | 10M |
| 실버 | 중위권 돌파 | 상위 50% 이내 5일 | 15M |
| 실버 | 꾸준한 상위권 | 상위 30% 이내 5일 | 20M |
| 실버 | 안정적인 흐름 | 상위 50% 이내 10일 | 15M |
| 골드 | 상위권 단골 | 상위 10% 이내 3일 | 25M |
| 골드 | 좋은 습관 | 상위 30% 이내 10일 | 15M |
| 골드 | 믿음직한 드라이버 | 상위 10% 이내 5일 | 25M |
| 플래티넘 | 무사즈 에이스 | 상위 10% 이내 10일 | 35M |
| 플래티넘 | 정교한 운전 | 상위 10% 이내 15일 | 35M |
| 플래티넘 | 꾸준한 좋은 흐름 | 서로 다른 3개 주에서 상위 10% 이내 | 20M |

- 각 티어의 3개 배지를 모두 획득해야 다음 티어가 열린다. 티어를 완성한 당일 경기는 다음 티어의 진행률에 중복 반영하지 않는다.
- 달성 횟수는 연속 참여가 아닌 서로 다른 참여일이다. 주간 조건은 한국시간 월요일~일요일 기준으로 주당 한 번 인정한다.
- 기존 순위 6종의 트로피 자산을 보존한다. 전환한 6종은 해당 티어의 기존 트로피 자산을 재사용한다.
- 배지 ID와 개별 보상은 유지한다. 예전 안전점수 기록은 순위 기록으로 환산하지 않는다. 이미 지급된 동일 ID 보상은 기존 지급 원장이 중복 지급을 막는다.
- 시연 모드의 실제 경기 흐름은 시연 순위·원장으로 집계한다. 달성 예시보기는 화면 미리보기이며 원장에 적립하지 않는다.
- 실제 서버 순위 연동은 기존과 같이 미완료다. 실제 모드에서는 명예 훈장에 ‘실제 순위 연동 준비 중’을 표시한다.
- 급가속·급감속·속도·안전벨트·방향지시등 채점 계산은 변경하지 않는다.

## 검증 계획 및 기록

1. 12종·티어별 3종, 순차 개방, 같은 날 재집계 방지, 서로 다른 주의 중복 방지를 코어 테스트로 확인한다.
2. 전체 순위 배지의 ID별 지급 금액과 반복 지급 방지를 테스트한다. 기존 고득점만으로 순위 배지를 받지 않는지 확인한다.
3. 에뮬레이터에서 필터·안내·티어·상세·트로피를 확인한다. 시연 경기 완료 후 마일리지 및 주간 기록을 다시 불러와 확인한다.

- 최초 테스트: 기존 구현에서는 새 12종·순차 개방 테스트 3개가 실패하는 것을 확인했다 (`rank12-red.log`).
- 구현 후: 코어 및 앱 단위 테스트와 debug 앱/테스트 APK 빌드 통과 (`rank12-build.log`, `rank12-tests-build.log`).
- 단위 테스트 219개 통과(실패·오류 0). 전체 순위 배지의 개별 보상 및 기존 고득점의 순위 전환 방지도 확인했다.
- 에뮬레이터: 배지 화면·시연 경기 연동 6개 통과 (`rank12-emulator.log`). 브론즈 3개/실버 잠금, 각 배지 상세 이미지, 안내 조건, 예시보기의 원장 미변경, 실제 시연 경기 후 30M 배지 적립, 플래티넘 주간 배지 20M 적립과 저장 복원을 확인했다.
- 추가 점수·내 기록 연동 검증: 기존 테스트가 하루 여러 경기를 허용한다고 가정한 부분을 하루 한 경기 규칙으로 수정했다. 마지막 실행에서 3개가 통과했고, 재참가 테스트의 내비 목적지 입력을 보완한 후 남은 3개도 통과했다 (`rank12-downstream-final.log`, `rank12-downstream-retry.log`). 앱의 점수 및 참가 규칙은 수정하지 않았다.
- 캡처: `android/app/build/verification/daily/badge-honor-rank-first-12quests.png`, `badge-tour-rank-12quests.png`, `badge-collection-guide-12quests.png`.
- 독립 코드 검토: 티어 개방, 주간 집계/저장, 보상 중복 방지, 시연/실제 분리에서 중요한 문제 없음.
