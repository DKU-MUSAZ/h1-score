# 하루 한 경기와 결과 연동 구현 계획

**Goal:** 하루 한 번의 참가를 영구 기록하고 인정된 결과만 배지·마일리지에 연결한다. 저장된 채점 근거로 개인별 피드백을 생성한다.

**Architecture:** 참가일은 참가 확정 시 한국시간으로 고정한다. 실제/시연 원장을 분리하고 결과 인정 여부를 공통 판정으로 사용한다. 점수 엔진과 실제 랭킹 서버는 변경하지 않는다.

**Spec:** 사용자의 2026-11-14 요청 및 직전 합의. 실격도 참여 소진, 실제 랭킹은 보류. 예약 확정 후 취소·확인 불가도 재시도로 제한을 우회하지 않도록 소진 유지. 내비 요청 실패는 참가 확정 전이므로 소진하지 않는다.

**Tech Stack:** Kotlin, SharedPreferences, Compose, JUnit, Android instrumentation.
