# 내 기록 주간 다이얼 개발 계획

## 동작

- 상단에 월요일부터 일요일까지 7일을 표시한다. 처음에는 가장 최근 주행일이 속한 주를 열고, 기록 목록은 전체를 보여준다.
- 좌우 스와이프와 이전 주·다음 주 버튼을 제공한다. 날짜를 수평으로 정렬하고 가운데 7일 양옆에 앞뒤 날짜를 이틀씩 옅게 표시한다. 날짜가 양끝으로 움직일 때는 기울기와 크기를 바꿔 휠 피커처럼 보이게 한다.
- 주를 넘기는 동안에는 목록의 날짜 필터를 유지한다. 날짜를 누르면 해당 날짜의 기록만 표시하며, 전체 기록을 누르면 필터를 해제한다.
- 달력과 정렬 컨트롤은 상단에 고정한다. 주행 기록만 아래에서 세로로 스크롤하고, 상세 화면에 갔다 돌아와도 주·날짜·정렬을 유지한다.

## 구현 및 검증

1. `HistoryDisplay.kt`의 날짜 계산을 월간 그리드에서 월요일 기준 주간 범위로 바꾼다. 월·연도 경계와 날짜 미상 기록을 기존 테스트로 검증한다.
2. `HistoryCalendar.kt`에서 Compose 수평 페이지와 날짜별 회전·이동·크기 변화를 연결한다. 접근성으로 각 날짜의 선택 상태와 기록 유무를 읽을 수 있게 한다.
3. `H1App.kt`에서 달력을 상단에 두고, 기존 카드와 상세 화면으로 이어지는 하단 목록을 `LazyColumn`으로 바꾼다.
4. Pleos에서 앞뒤 스와이프, 월 경계, 날짜 필터, 정렬, 상세 복귀, 목록을 스크롤할 때 달력의 위치를 확인한다.
