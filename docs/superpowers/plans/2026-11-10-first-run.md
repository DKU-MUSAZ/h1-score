## Global Constraints
- 기존 사용자 기록/잔액 삭제 금지. 설치 후 자동 실행은 1회, 업데이트 시 보존.
- 앱 이름 안운잘부 / 음성 무사즈. SSO 연동 완료라고 표현하지 않음.
- 주차 중 설정·안내만 허용. 새 데이터나 제휴·운영 정책을 지어내지 않음.
