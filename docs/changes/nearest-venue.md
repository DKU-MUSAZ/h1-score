# 목적지 기준 가장 가까운 개최지 배정

## 규칙

1. 원본 목적지의 실제 위도·경도를 사용한다. 현재 차량 위치, 검색어 문자열, 경로 주행거리는 사용하지 않는다.
2. 모든 등록 개최지 중앙점까지 Haversine 직선거리(m)를 계산한다. 인기 목록의 10명 기준은 이 탐색에 적용하지 않는다.
3. 가장 가까운 개최지 하나를 고른다. 정확히 같은 거리면 영구 개최지 ID 사전순으로 결정한다.
4. 최소 거리가 **1,000m 이하**면 그 개최지의 대회 대상이다. 여러 반경 안에 있어도 가장 가까운 중앙점 하나만 고른다.
5. 최소 거리가 **1,000m 초과**면 대회 세션을 만들지 않고, 원본 목적지를 유지한 채 기존 내비 화면을 연다.
6. 좌표가 없거나 유효하지 않거나 최신 내비 정보가 아니면 판정을 보류한다. 좌표 오류를 범위 밖으로 취급하지 않는다.

목적지로 선택한 상점 A와 상점 B가 같은 개최지에 가장 가까우면 같은 회차에 같은 `competitionId`를 받는다. ID는 `개최지 ID:회차 시작 시각`이다. 경로 변경 감지용 원본 `destinationId`는 별도로 보존한다. 참가 후 경로를 바꾸면 기존처럼 기록을 취소하며 다른 대회로 기록을 몰래 이전하지 않는다.

## 화면과 내비 흐름

내비에서 실제 장소 선택·안내 시작 → 앱으로 돌아오면 목적지와 배정 개최지/거리 표시 → 기존 회차·벨트·주차·동의 조건을 만족하면 참가한다. 대상이 아니면 **내비로 계속** 버튼으로 선택했던 목적지의 일반 안내를 유지한다. 저장한 바로가기 역시 좌표를 내비에 전달한다. 개최지 마커를 직접 누르는 경우에만 개최지 자체를 새 목적지로 요청한다.

거리 판정이 기존 동의·주차·벨트·회차 제한이나 순위 참여를 위한 10km 주행 조건을 없애지는 않는다. 가장 가까운 곳이 범위 밖인 일반 내비 사용은 대회 회차 시간과 관계없다.

## 직접 입력해 볼 목적지

| 내비 검색어 | 예상 배정 |
|---|---|
| 여의도한강공원 | 여의도한강공원 대회 |
| 현대 모터스튜디오 고양 | 고양 모터스튜디오 대회 |
| 단국대학교 죽전캠퍼스 | 단국대 죽전 대회 |
| 서울숲 | 서울숲 대회 (9명이어도 배정 가능) |
| 올림픽공원 | 올림픽공원 대회 (6명이어도 배정 가능) |
| 서울역 | 일반 내비 (현재 등록 개최지들에서 1km 초과) |

검색 결과 중 해당 시설을 선택한다. 내비 POI/출입구의 실제 좌표가 최종 기준이므로 표시 이름만으로 강제 배정하지 않는다. 회차 시간 밖에는 ‘대회 대상’이어도 참가 시작이 제한된다.

## 겹침/경계 자동 테스트

현재 다섯 개최지 중앙점은 서로 멀어 실제 반경 겹침 사례가 없다. 임의 장소를 운영 데이터에 추가하지 않고 다음 합성 좌표로 겹침을 검사한다.

- A 중앙점에서 동쪽으로 1,200m 위치에 B 중앙점을 둔다. 각각 반경 1,000m.
- A에서 동쪽 800m 목적지: A까지 800m, B까지 400m → **B**.
- A에서 동쪽 400m 목적지: A까지 400m, B까지 800m → **A**.
- 999.999m, 1,000m 포함 / 1,000.001m 제외.
- 완전히 같은 거리의 개최지 목록을 뒤집어도 동일 ID 선택.
- NaN·잘못된 좌표·빈 개최지 목록은 배정 없음.

실행(android 디렉터리): `JAVA_HOME=<JDK21> ./gradlew :core:test --tests '*VenueMatchingTest'`

기기 통합 검사: `CollectionRecordingTest#nearestVenueAssignsNonHangangWithoutChangingDestinationAndOutsideOpensNavigation`. 올림픽공원 중심점의 서로 다른 두 POI가 같은 대회 ID를 받는지, 원래 경로 ID 유지, 서울역은 세션 없이 내비 실행, invalid 좌표는 내비 강제 실행 없이 보류를 검사한다. 이 검사는 내비 수신 좌표를 주입하며 실제 외부 내비 검색/주행의 종단 검증을 대신하지 않는다.

## 구현 범위

앱의 로컬 배정·세션 식별까지 구현했다. 여러 사용자 사이의 실제 참가 명단/서버 순위 집계는 별도 백엔드 연결이 필요하다. 카카오맵 네이티브 렌더러의 에뮬레이터 이슈는 거리 계산과 별개다.

검증 결과: 코어 42개 테스트(최근접 배정 5개 포함) 통과, 실제 에뮬레이터에서 배정/일반 내비 분기 통합 검사 1개 통과, APK 빌드 및 설치 완료. 코드 리뷰에서 중대 결함 없음. 실제 외부 내비 앱의 경로 안내 완료까지는 별도 확인 대상이다.
