# 목적지 바로가기와 챌린지 지도

브랜치: `codex/home-work-destinations`

## 변경한 동작

- 집·회사와 사용자가 추가한 학교·운동장 등을 같은 바로가기 목록으로 관리한다. 이름은 1~12자, 최대 10개, 중복 이름을 허용하지 않는다.
- 편집 → 새 바로가기 → 내비 검색 → 내비에서 목적지 선택 및 안내 시작 → 앱으로 돌아와 현재 목적지를 확인 → 저장한다. 검색어 자체를 목적지로 저장하지 않는다.
- 저장 값은 실제 내비가 전달한 장소명과 위도·경도다. 바로가기를 다시 누르면 Pleos `requestRoute`에 이 좌표를 전달한다. SDK 요청 성공은 실제 경로 안내 완료를 보장하지 않는다.
- 과거 문자열 설정은 검색어로 보존한다. 좌표가 없으므로 장소를 다시 선택해야 한다. 기존 값을 임의 좌표로 변환하지 않는다.
- 편집·삭제는 주차 상태에서만, 외부 내비 실행은 실제 차량의 주차 상태까지 확인한다.

## 인기 스팟 ↔ 카카오 지도

공통 `challengeSpots`가 장소명·좌표·시연 참가자 수를 제공한다. 인기 목록은 **10명 이상**, 참가자 수 내림차순(동률은 이름순), 상위 3개다. 지도에는 10명 미만도 표시한다. 장소 전체 인원과 보상 비교조 인원은 구분한다. 기존 정산 규칙은 최대 5명(나+4명)이므로 순위표는 ‘시연 비교조’로 표시한다. 장소 인원이 증가해도 기존 보상 규칙을 임의로 변경하지 않는다.

| 장소 | 시연 인원 | 인기 목록 |
|---|---:|---|
| 여의도한강공원 | 24 | 포함 |
| 현대 모터스튜디오 고양 | 18 | 포함 |
| 단국대학교 죽전캠퍼스 | 10 | 포함 |
| 서울숲 | 9 | 제외 |
| 올림픽공원 | 6 | 제외 |

목록을 누르면 해당 장소로 카카오 지도 카메라가 이동한다. 마커를 누르면 같은 장소의 상세 화면이 열린다. 지도 검색도 이 공통 데이터에서 찾는다. 카카오 지도가 실패하면 가짜 지도를 그리지 않고 장소 목록을 표시한다.

인원은 서버 집계가 아닌 시연 fixture다. 카카오맵은 지도·마커를 제공하며 챌린지 참가자 수는 제공하지 않는다. 운영 시 행사/장소 ID와 서버 집계 인원을 연결해야 한다. 신규 장소 좌표는 지도 표시용 대표 지점이며 정밀 출입구 좌표는 아니다. 목적지 기준 가장 가까운 개최지의 1km 안이면 해당 개최지로 로컬 세션을 배정한다. 상세 규칙과 일반 내비 분기는 [최근접 개최지 배정](nearest-venue.md)을 따른다.

## 디자인

사이드바에 작은 도로 마크와 앱 이름을 한 번만 표시하고 본문 헤더는 현재 화면 제목(챌린지·내 기록 등)으로 표시한다. 로고/앱 이름은 메뉴와 같은 8dp 여백·34dp 아이콘 영역·8dp 간격에 맞춘다. 기본 보라색 설정 팝업을 흰 바탕의 장소 관리 화면으로 변경했다.

참고: [Google 자동차 앱바](https://developers.google.com/cars/design/automotive-os/components/app-bar), [Apple CarPlay](https://www.apple.com/ios/carplay/), [Kakao Android v2 Label](https://apis.map.kakao.com/android_v2/docs/api-guide/label/label/).

## 검증

- `JAVA_HOME=<JDK21> ./gradlew :core:test :app:assembleDebug :app:assembleDebugAndroidTest` (android 디렉터리)
- `CollectionRecordingTest`: 실제 좌표 저장·재실행 유지·이름 변경·삭제, 주행 중 변경 차단, 9/10/11명 경계, 학교 바로가기 UI, 인기 스팟 선택 후 지도 이동.
- `MapChallengeTest#challengeHomeOpensSearchSuggestionsAndExistingMap`: 앱 홈 → 인기 목록 → 지도 → 돌아가기 회귀 검사.
- 내비가 전달한 목적지는 테스트에서 주입한다. 실제 내비 장소 선택부터 경로 안내 시작까지의 종단 검증은 별도이며, 자동 테스트 통과와 구분한다.

검증 기록: 코어 37개 테스트 통과. 최초 기기 검사 5개 통과. 스크린샷 추가 후 반복 실행에서 실제 차량 상태와 테스트 주입 값의 경쟁이 발견되어 UI 테스트는 시연 상태로 격리했다. 단독 재실행은 통과했다. 카카오 지도 종료 시 소프트웨어 렌더러 시간 초과 및 에뮬레이터 화면 정지가 관찰되어 지도 실기기 렌더링은 추가 확인이 필요하다.

시연 주행 회귀 검사에서 10명 이상 fixture를 기존 최대 5인 정산에 넘기면 예외가 발생함을 확인했다. 전체 장소 인원과 비교조 인원을 분리하고 정산 입력을 나+최대 4명으로 제한했다.

최종 확인: 코어 37개 통과, 분리 실행한 기기 테스트 4개(시연 완료 정산 포함) 통과, 실제 앱 인기 목록 UI 검사 1개 통과. 총 5개 기기 검사는 서로 다른 실행에서 확인했다. 최신 APK 설치 완료. 네이티브 카카오 지도 렌더링 및 실제 내비 종단 동작은 완전 검증으로 표시하지 않는다.
