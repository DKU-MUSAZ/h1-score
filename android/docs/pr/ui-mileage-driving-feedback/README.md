# UI 개선 시연 캡처

Pleos Connect 에뮬레이터의 앱 시연 모드에서 촬영한 화면입니다. 실차 검증 자료가 아니며, 기존 시연 주행 기록과 시연 교환 내역을 사용합니다.

화면 왼쪽의 차량·안전벨트 표시는 에뮬레이터 기본 UI입니다. 앱 화면은 오른쪽 영역에 표시됩니다.

| 화면 | 확인 내용 |
| --- | --- |
| [홈](01-home.png) | 남색 통계 원, 마스코트 배치, 확대된 검색창 |
| [마일리지](02-mileage.png) | 왼쪽 잔액 카드와 오른쪽 가로형 교환 항목 |
| [쿠폰함](03-coupons.png) | 시연 교환 내역과 고정 사용기한 |
| [잔액 부족](04-insufficient-mileage.png) | 쿠폰 교환 질문, 부족 금액 경고, 교환 버튼 비활성화 |
| [마이페이지](05-profile.png) | 차량 상태 항목과 튜토리얼 다시보기 |
| [튜토리얼](06-tutorial.png) | 가입 정보 초기화 없이 메뉴 안내 다시보기 |
| [주행 결과](07-driving-result.png) | 원형 점수 표시, 감점 요약, 참가자 영역 배치 |

## 재현 방법

1. 주차 상태에서 오른쪽 위 연결 상태 버튼을 누르고 **시연 모드 켜기**를 선택합니다.
2. 홈·마일리지·마이페이지 메뉴를 차례로 확인합니다.
3. 마일리지에서 **나의 쿠폰함**을 열어 기존 시연 교환 내역을 확인합니다.
4. 보유 마일리지보다 비용이 큰 혜택 카드를 눌러 부족 경고와 비활성화된 **교환하기** 버튼을 확인합니다. **취소**로 닫으면 잔액이 유지됩니다.
5. 마이페이지의 **튜토리얼 다시보기**로 메뉴 안내를 확인합니다.
6. 주행 결과는 기존에 완료된 시연 기록을 다시 연 화면입니다. 감점 이벤트의 위치는 GPS가 아닌 경과 시간·유효 샘플 누적 거리 기준입니다.

현재 위치 기반 주변 정비소 탐색과 실제 제휴 쿠폰 발급은 포함하지 않습니다.
